# Fibonaipe

Planning poker (Fibonacci + naipe de risco) com gestão de sprint, observabilidade de estimativas e previsão estatística.

A documentação de produto e de implementação está em [`.docs/requirements.md`](.docs/requirements.md). As specs de implementação ficam em [`.docs/specs/`](.docs/specs/). A ordem de execução está em [`.docs/todo.md`](.docs/todo.md).

Copie [`.env.example`](.env.example) para `.env` e preencha os segredos no servidor. O arquivo `.env` não entra no Git.
