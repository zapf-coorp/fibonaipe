# R4 forecast accessibility

- The forecast card always requires and renders its translated statistical-estimate disclaimer.
- Insufficient-data state is announced with `role="status"` and renders the eligible sprint count without a predicted value.
- The chart has an accessible image label and is paired with an HTML table containing the same filtered series.
- Period controls use native date inputs with visible labels. SVG and data exports use explicit button labels.
- Team observers can read the dashboard but receive `FORBIDDEN` from CSV and JSON export routes; the UI also hides those export controls.
